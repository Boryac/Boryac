# Boryac

AI × 商务拓展。做检索和系统，也做内容与增长。

**站点**：[boryac.me](https://boryac.me) — 三维档案式作品集（18 条项目档案，含两条 AI 影像）
**产品**：[yikang.boryac.me](https://yikang.boryac.me) — 弈康 YiKang，家庭健康信息整理助手

## 在做什么

- **检索系统**：混合检索（全文 / 分词 / 向量 / 重排）与降级设计，宁可少答不硬编
- **增长与运营**：B 端线索分层、订单流程并行化、内容账号的选题机制
- **工程实现**：Electron + Vue3 + FastAPI 桌面端；EPUB 精排引擎；静态站构建管线
